# Nugs Release Essays have been added to the Article Library

Recently I went through the Nugs blog and pulled all of the essays written by Erik Flannigan. These accompany the monthly archive releases, and are well written pieces covering the shows being released. Acting as a mini-review of the show.

These have been added as articles, and are linked on the Nugs Releases table as well as the Event Detail page.

# User Profile Changes

As I've alluded to in various places, I've never been entirely happy with the User Profile layout. Always finding it a tad cumbersome with the many tables and controls.

This month I greatly simplified it. Removing the many tables and going with a cleaner approach inspired by WTED Archives.

{% include figure popup=true img1="/assets/img/blog/2026-10-06-databruce-1.21/profile.png" alt="User Profile Overview Tab, with cards for most seen/most played not seen/rare songs." caption="Much cleaner than tables, and much simpler too." %}

The new "Overview" tab has a series of list cards for your song stats. Currently it shows your most seen songs, most played not seen (100+ plays), and rare songs (<100 plays). I might expand this in the future with more cards from WTED but for now this works.

The cards also have a "copy" icon to quickly copy the data as a text based list. Eventually I want to do something similar for the main event/songs table, but didn't have time this month. That might take the form of a Datatables export in CSV/PDF/XLSX.

# Table Control Changes

{% include figure popup=true img1="/assets/img/blog/2026-10-06-databruce-1.21/filter-collapse.png" alt="Filter button showing/hiding the table controls, dropdowns and search boxes" caption="Collapsing these makes things look less cluttered on mobile" %}

I've gone through and moved all table controls into a collapsible "filters" element, visible above all tables. While all the dropdowns/searches look good on desktop, they're an absolute mess on mobile. This collapse collects them all and hides them until needed. This has the added benefit of being able to now add more filters down the line and not have to worry about them taking up the whole page.

# URLs changed to use Slugs instead of UUID

```
Old: /songs/8e3a662a-b164-4409-8c03-29da0a29f0a9
New: /songs/born-to-run
```

If you've been using the site and have seen the error page a ton, this is why, apologies.

I started the process of switching the URLs over to use slugs instead of UUIDs. These look nicer, and are easier to use in general. It's immediately clear what page a link leads to.

So far the following have been switched over:

- Tour/Tour Leg detail
- Song detail
- Event run detail
- Venue detail
- Band detail

I also plan on switching the following over at some point:

- City/State/Country detail
- Relations
- Song lyrics
- Releases
- User Profile

The process has been a bit iffy, simply because I wasn't aware of just how many places the UUID urls were used, hence the previously mentioned errors.

# Event Search Keyboard Input

Last month I added the ability to open the event search with a hotkey (CTRL/CMD + K). Now the modal has been updated so that you can navigate with the keyboard. I went with the defaults used by Algolia search: arrow keys to navigate, Enter to submit, ESC to close.
